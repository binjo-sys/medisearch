# MediSearch Learning Content

MediSearch learning content is organized by learner track so the depth and clinical framing can differ for each audience.

## Tracks
- Diploma Nursing
- University Nursing / BSc Nursing
- Clinical Medicine & Surgery / Clinical Officer
- Medicine / MBChB / Medical Officer
- Higher Diploma Clinical Officer specialties
- Cross-track Clinical Cases and OSCE practice

## Standard note structure
Each major topic should contain learning objectives, core explanation, key clinical points, investigations where appropriate, management overview where appropriate, complications/red flags, practice questions, and references with source/date information.

## Content rule
Educational background should be distinguished from current clinical guidance. Copyrighted textbooks should be represented through lawful licensing, permitted excerpts/metadata, or legitimate external links rather than full-book reproduction.
